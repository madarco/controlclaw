Extra sign-in addresses optional

One exact address per line. /session is on the sign-in page's own site; for another of the sites above, write it first: api.example.com/auth/login. An extra address is still a sign-in: the password goes only into a field named like a password (password, pwd, pass, user_password…) of an ordinary form, or into a top-level field with such a name of a JSON request. It does not make a general API address work.

  • Add only an address that does nothing but sign in. On an address that also does other things (a general API or a GraphQL address), a tricked agent could send your password there in a field named like a password, and the site would do with it whatever that request asks.
  • An address ending in /* covers everything under it, so the password may be sent to any page there. Use it only when the sign-in address changes every time, never for a folder where people can post. / and /*, a site's top page and the whole site, are not accepted.
