Only if Activity shows this login "blocked, not on its sign-in page" while the agent was signing in. One per line, each one exact address. A path such as /session is on the sign-in page's own site; to name another of the sites above, write it first: api.example.com/auth/login. An extra address is still a sign-in: the password is put in only into a field named like a password (password, pwd, pass, user_password…) of an ordinary form, or into a top-level field with such a name of a JSON request. It does not make a general API address work. Add only an address that does nothing but sign in. On an address that also does other things (a general API or a GraphQL endpoint), an agent that was tricked could send your password there in a field named like a password, and the site would do with it whatever that request asks. Ending in /* an address covers everything under it, so the password may then be sent to any page there: use it only when the sign-in address changes every time, and never for a folder where people can post. / and /*, the top page of a site and the whole site, are not accepted.

Import from a password manager

Export a CSV from 1Password, Bitwarden or Chrome, and pick it here. It is read in this page and sent only to your firewall. The agents you ticked above get the logins. Delete the CSV file afterwards: it holds every password in plain text.

Connect 1Password

Let your agents use the logins in one or more 1Password vaults. In 1Password, make a service account with read access to a vault for your agents (not your personal one), and paste its token here. The token stays on your firewall; the logins are read from 1Password every hour and are used exactly like the ones above. The agents you ticked in the form above get them.

This site needs you to sign in yourself (Google or Microsoft sign-in, a passkey, a CAPTCHA). You do it in the agent's own browser; only the signed-in session stays there.

  1. Press Open the agent's browser. The site opens in a new tab of the agent's browser, and the agent's screen opens here.
  2. Sign in there as you normally would.
  3. Come back to this page and press I have signed it in.

While you sign in, the agent can see its own screen. Password fields show dots. To sign the agent out later, delete this login in ControlClaw (Secrets, Logins). If you sign in with Google or Microsoft, the agent's browser also stays signed in to that account: deleting the login does not undo that, so use an account made for the agent, or sign it out of that account in the agent's browser.
